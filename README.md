# Bitvoy feedback

Report bugs, request features and ask questions about [Bitvoy](https://bitvoyhq.com), the iPhone and Android app for Bitbucket Cloud.

This repository holds issues only. Bitvoy's source code isn't public.

## Before you post

- **Search first.** Someone may have reported it already; add a 👍 or a comment to their issue instead.
- **Keep it public-safe.** Everything here is public. Don't paste tokens, private code, repository or workspace names you'd rather keep private, or screenshots that show them. Blur or crop first.
- **Security problems** go by email to [hello@bitvoyhq.com](mailto:hello@bitvoyhq.com), not here. See [SECURITY.md](SECURITY.md).

## Open an issue

- [Report a bug](https://github.com/Bitvoy-HQ/feedback/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/Bitvoy-HQ/feedback/issues/new?template=feature_request.yml)
- [Ask a question](https://github.com/Bitvoy-HQ/feedback/issues/new?template=question.yml)

In the app, **Profile → Settings → About & support → Report a bug** opens the bug form with your app version and device filled in.
